This project practices Flexbox and CSS Grid by building a set of FC Barcelona themed pages. Flexbox was used for the navigation bar and card layouts, while CSS Grid was used for the page layout, image gallery, and the main content area of the portfolio page. Both techniques were combined in the final task to build a responsive layout.
